This is a draft template. Copy this file, rename it, set `draft: false`, and write your content.

## Adding images

Put images in `public/blog/your-post-slug/` and reference them:

```md
![Alt text](/blog/your-post-slug/hero.jpg)
```

Or set `image: /blog/your-post-slug/hero.jpg` in frontmatter for a hero image.
